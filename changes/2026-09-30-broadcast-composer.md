# Общая отправка сообщений

Дата: 2026-09-30

- Добавлена отдельная верхняя строка `ALL BOTS` с полем сообщения и кнопкой `Send to all`.
- Сообщение отправляется из фонового потока по всем подключённым аккаунтам, в том числе работающим в Flood Mode.
- Интервал между отправками настраивается от 0 до 5000 мс, по умолчанию 100 мс.
- Нижнее поле отправки остаётся одним постоянным composer для выбранного аккаунта; переключение аккаунтов не создаёт новые поля.
- Кнопка блокируется на время общей отправки, а журнал показывает результат отдельно для каждого аккаунта.
