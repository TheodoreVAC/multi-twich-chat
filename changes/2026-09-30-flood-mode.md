# Настройка Flood Mode

Дата: 2026-09-30

## Поведение

- Flood отправляет не чаще одного сообщения на аккаунт примерно раз в 4–5 минут.
- Flood-аккаунты дополнительно используют общий интервал минимум 15 секунд между отправками, чтобы не писать одновременно.
- Выбор остаётся случайным среди включённых сообщений, доступных аккаунту.
- Повтор пресета запрещён для всех аккаунтов минимум пять часов после его отправки.
- Общая история переживает перезапуск. Старые записи по аккаунтам переносятся в общий список; для пресета учитывается самая поздняя отправка.
- Параллельные аккаунты резервируют пресеты под блокировкой, чтобы не отправить один и тот же текст одновременно.
- Когда варианты закончились, конкретный аккаунт получает предупреждение `MESSAGES USED` в списке аккаунтов и сообщение в журнале. Flood ждёт ближайшего освобождения варианта и затем продолжает работу.
- Неудачная отправка освобождает резерв пресета.

## Сообщения

`messages.txt` содержит короткие нейтральные русские реплики со строчными буквами, подходящие для разных каналов. Все сообщения включены для всех аккаунтов; задержки заданы в диапазоне 240–345 секунд.
